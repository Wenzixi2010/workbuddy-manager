# Key 账号范围列表与指定账号模型测试

## Key 列表

新增「绑定账号」和「可使用账号」两列，展示昵称/备注、realm:UID 和数量；超过两条可展开全部。

- 绑定账号是 Key 保存的选择与白名单/独占模式，删除的账号保留占位显示。
- 可使用账号按实际转发共用规则计算：Key 选择、账号允许 Key、同池独占及 Key 版本共同判断。
- 未选择账号范围显示公共池，并排除专属占用账号。范围规则不会因 Key 停用/过期被释放。
- 这里只说明权限范围；Key 过期/禁用/额度、账号余额/冷却/模型限流可能导致实际调用失败。手动禁用、凭据过期/无效单独标注。
- 上游被删除、账号目录未配置/不可读显示未知或错误，不把无法读取说成零账号。远程无本地目录的池不能枚举账号。
- 只下发账号 ID/名称和安全状态，不下发 Token、完整 Key、代理凭据或文件路径；列表不向腾讯/上游发请求。

## 模型页指定账号

管理员在模型页「测试账号」下拉选择默认上游的一个账号，再点模型行测试，发送 Ciallo。默认仍公共池；指定账号包括专属账号，可用于管理员诊断。

- 后端校验账号存在于默认上游、版本一致且凭据可加载；已手动停用/过期不能选择。
- 只签发本次请求的单账号范围，走现有 scoped API。指定账号不可用即失败，不回退借用其它账号。
- 不修改任何 Key/账号永久权限，正式 Key 调用的限制仍完整保留。选择专属账号并不授予某个 Key 调用权限。
- 指定账号接口仅管理员会话，拒绝普通用户及管理 API Token；要求上游已安装账号隔离版本1。凭据留服务端。
- 国内/国际切换后重置选择；弹窗显示本次使用的账号。不支持从默认上游以外的分组选择账号（Key 列表可显示其它分组范围）。
- 消耗真实积分、记请求日志；指定账号操作写审计日志。模型/余额/风控限制仍可能失败。

从定制 GitHub main 拉取后重建管理端镜像并 recreate；挂载/GID 不需要再次修改。不要使用官方自动更新覆盖定制代码。
