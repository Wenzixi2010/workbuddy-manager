# 模型分组、精简 Key 列表和模型测试弹窗

## 模型分组

进入「密钥 → 模型分组」创建/编辑分组，在分组设置选择允许使用的模型（至少一个）。可限制国内/国际版本，也可不限制版本。

Key 设置里只选择模型分组，不再单独选择模型。分组中的模型权限由所有选用它的 Key 共享，修改后对后续请求生效。未选分组不在列表显示分组标签；选了才显示分组名。限定版本的分组会让 Key 设置跟随该版本；模型调用仍须使用正确的版本前缀。

默认未选择模型分组就允许全部模型，不自动创建任何分组；分组仅由管理员按需手动创建并选择。旧 Key 的独立模型白名单不再作为隐藏限制，也不再自动迁入分组。已被 Key 使用的分组不能删除；空/无效/已丢失分组拒绝模型调用，不解释为不限模型。

备份包含手动模型分组和 Key 的关联，旧版没有分组表的当前备份仍可恢复，但不会为旧模型白名单自动创建分组。账号范围、版本、配额和启停限制独立保留。

模型选择下拉在手机支持列表内上下滑动：浮层使用独立滚动锁，列表限制为视口可用高度，搜索/筛选栏固定，列表可滚动。手机打开时不自动弹出键盘，点击搜索框才输入；不会解除父弹窗的背景滚动锁。

## 精简 Key 列表

移除可使用账号列。Key 名称最右侧仅在有独占绑定账号或模型分组时显示圆形下三角按钮，默认收起；点击后在按钮下方打开悬浮详情窗，右边缘与按钮右边缘对齐，显示独占账号（昵称/备注、ID、数量）和已选择的模型分组，不撑高表格行；再次点击、点击外部或按 Escape 关闭。悬浮窗在窄屏时按可用空间收窄并滚动。普通白名单/公共池不显示账号块。没有独占账号和模型分组时不显示按钮，不添加额外宽列。

账号权限判断与正式调用保持原样；只调整展示，不释放已停用 Key 的独占账号。

## 模型测试弹窗

点击模型行「测试」先打开弹窗，不立即发送请求。弹窗内部有「测试账号」下拉、刷新账号按钮和「发送 Ciallo」按钮；选择账号后再发送，结果/本次账号显示在同一弹窗。

默认公共池；管理员也可选默认上游的单个专属账号做一次诊断。后端仍校验存在/版本/凭据及账号隔离协议1；指定账号失败不回退，不更改持久权限。按钮在发送中锁定，避免重复消费。模型生成消耗真实积分，关闭等待不能保证上游停止计费。

仅管理员会话允许指定账号；非默认上游账号不在选择器中。切换国内/国际版清空选择和旧弹窗。正式 Key 的配额、账号规则与模型分组仍各自生效。

## 部署

源码从定制 GitHub main 拉取，只重建/recreate 管理端；保留现有 Docker socket 和实际 GID 挂载。用户本次要求不运行测试、不发送模型请求：仅进行必要构建、备份与部署状态检查。官方自动更新保持关闭。

## 模型倍率和账号池繁忙度

模型选择下拉每项显示腾讯/上游提供的 credits 倍率，模型页有独立倍率列；未提供显示破折号，不把缺失当免费。倍率为目录原始值，不在管理端自行更改实际扣费。

模型页「账号池繁忙度」读取默认上游 /status 的当前国内/国际版本统计，每 15 秒刷新，可手动刷新。显示在途请求、占满并发的账号 / 健康账号、冷却/禁用账号，以及占满比例和采样时间。接口只下发聚合计数，不下发账号 Token、身份或原始错误。

腾讯目录没有提供每个模型的官方繁忙度。此指标是账号池总体并发占用，不是厂商全局负载或某个模型的独立繁忙度；包含专属账号，并不等于当前 Key 的可调用容量。没有账号/健康账号时显示不适用，状态获取失败/旧上游缺少分版本计数时显示未知，不沿用旧值冒充实时数据。
